# Tutorials

These six executable guides move from method selection to focused workflows.
Every dataset is deterministic and local, and every code cell runs during the
documentation build against the packaged wheel.

  </a>
  <a class="landing-card" href="../guides/distance-and-graph-embeddings.html">
    <h2>Distance and graph embeddings</h2>
    <p>Work through distance, kernel, neighborhood-graph, diffusion, and alignment methods.</p>
  </a>
  <a class="landing-card" href="../guides/stress-and-stochastic-embeddings.html">
