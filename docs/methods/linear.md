# Linear methods

The linear family contains twelve estimators for unsupervised latent
representations, supervised or paired projections, inverse regression, and
feature selection. Open a card for its assumptions, fitted attributes,
diagnostics, limitations, citation, and executable example.

  <a class="method-card" href="../examples/gaussian_random_projection.html"><span class="method-card-title">GaussianRandomProjection</span><span class="method-card-description">A seeded Gaussian projection scaled by the target dimension.</span></a>
  <a class="method-card" href="../examples/factor_analysis.html"><span class="method-card-title">FactorAnalysis</span><span class="method-card-description">Gaussian latent factors fitted with the Rubin–Thayer EM algorithm.</span></a>
  <a class="method-card" href="../examples/probabilistic_pca.html"><span class="method-card-title">ProbabilisticPCA</span><span class="method-card-description">Closed-form isotropic-noise probabilistic principal components.</span></a>
  <a class="method-card" href="../examples/fast_ica.html"><span class="method-card-title">FastICA</span><span class="method-card-description">Symmetric fixed-point recovery of statistically independent sources.</span></a>
  <a class="method-card" href="../examples/sparse_pca.html"><span class="method-card-title">SparsePCA</span><span class="method-card-description">Elastic-net sparse loadings for interpretable components.</span></a>
  <a class="method-card" href="../examples/linear_discriminant_analysis.html"><span class="method-card-title">LinearDiscriminantAnalysis</span><span class="method-card-description">Fisher–Rao supervised projection for labeled classes.</span></a>

  <a class="method-card" href="../examples/sliced_inverse_regression.html"><span class="method-card-title">SlicedInverseRegression</span><span class="method-card-description">Response-sliced inverse-regression directions.</span></a>
  <a class="method-card" href="../examples/sliced_average_variance_estimation.html"><span class="method-card-title">SlicedAverageVarianceEstimation</span><span class="method-card-description">Conditional-variance directions beyond inverse means.</span></a>
